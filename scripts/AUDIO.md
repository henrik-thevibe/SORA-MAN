# Audio tools

Every sound in SORA-MAN is generated by the scripts in this folder. No recorded audio ships. This page explains the pipeline and how to rerun it.

The audio went through three passes; the story is in the [README](../README.md#2-the-audio-overhaul):

1. arcade recordings, now removed
2. [jfxr](https://github.com/ttencate/jfxr) patches
3. the contour-matched synthesis that ships.

All three toolchains are here except the recordings.

## Pipeline

```
audio-kit.js ─┐
              ├─ astra-voices.js ─┬─ generate-astra-audio.js     (17 gameplay clips) ─┐
              │                   └─ generate-astra-ui-audio.js  (boot, menu, UI)     ├─ assets/audio/*.wav ─ build-audio.py ─ sound-bank.js
audition-page.js ────────────────────────────────────────────────────────────────────┘                                     + manifest.json
boot-timeline.js ─ generate-astra-ui-audio.js and game.js (one source for the boot's chomp timing)

generate-jfxr-demo.js ─ tools/jfxr (not included) ─ outputs/jfxr-demo-set/   (the jfxr pass, audition only)
```

| File | Role |
|---|---|
| `audio-kit.js` | The synthesis kit. It covers the WAV reader and writer, 60 Hz frame helpers and note tables, envelopes, oscillators (voice and wavetable), noise, filters (low- and high-pass), bit-crush and decimation, echo and stutter, seamless loops, loudness, and pitch tracking (`tickPitches`) and contour matching (`contourMatch`). No dependencies. |
| `astra-voices.js` | Shared instruments: bit-clicks, shimmer, lead and bass notes, blips and hats, plus the boot-03 motif. Both generators use them, so the whole game has one voice. |
| `generate-astra-audio.js` | The gameplay set: chomps, five sirens, frightened, returning eyes, ghost and fruit eating, power-up, zap, extra life, death, the boot jingle and the intermission. Each sound follows a pitch contour measured from its arcade counterpart (the `CONTOUR` table) with a new timbre. Loudness targets are in `TARGET_RMS`. |
| `generate-astra-ui-audio.js` | Boot intro, title sting, the 12-second menu loop, UI blips, the shop, results, alarm, victory and ready-up. Some clips have A/B candidates; `--pick` chooses among them. |
| `audition-page.js` | Builds the side-by-side HTML audition pages, with contour plots and keep/revise buttons. |
| `build-audio.py` | Packs `assets/audio/*.wav` into `sound-bank.js` (base64 PCM, so the game makes no audio requests and works from `file://`). It also writes `manifest.json` with each clip's duration, loop points, loudness and hash. Python standard library only. |
| `generate-jfxr-demo.js` | The jfxr pass: parameter-driven jfxr patches and sequenced music cues. It writes an audition set with editable `.jfxr` sources. |

## Rebuilding the shipped sounds

Node 20+ and Python 3:

```bash
node scripts/generate-astra-audio.js --check
node scripts/generate-astra-audio.js --install
node scripts/generate-astra-ui-audio.js --check
node scripts/generate-astra-ui-audio.js --install --pick=menuLoopB,uiMoveB
python scripts/build-audio.py
node tests/audio.test.js
```

Run a generator without flags to write an audition page to `outputs/`, which isn't tracked.

### The arcade references are optional

`generate-astra-audio.js` has an extra quality gate that uses the original arcade recordings in `assets/audio/reference/`. With the gate on, a clip isn't installed unless at least 85% of its voiced frames are within a semitone of the reference. Loop seams are always checked.

**Those recordings belong to their rights holders and are not in this repository.** The sounds are built from the contour table hard-coded in `CONTOUR`, so the generator needs nothing external. Without the reference folder, it prints a warning, skips the contour gate, and leaves the "original" players out of the audition page. The output is identical: all 17 clips regenerate byte for byte.

To turn the gate on, use `assets/audio/sources.json`. It records where the analysis copies came from (a public repository), with each file's URL and SHA-256.

1. Fetch those MP3s yourself.
2. Check their hashes.
3. Convert each to mono 44.1 kHz WAV with the same base name in `assets/audio/reference/`, for example `ffmpeg -i eating.mp3 -ac 1 -ar 44100 eating.wav`.

## Rebuilding the jfxr pass

jfxr isn't vendored. Clone it at the revision used, and build its library:

```bash
git clone https://github.com/ttencate/jfxr tools/jfxr
git -C tools/jfxr checkout e971e4c183beddaff3abcebb77f2eaae17a2b83b
npm --prefix tools/jfxr/lib install
npm --prefix tools/jfxr/lib run build
node scripts/generate-jfxr-demo.js
```

This produces `outputs/jfxr-demo-set/`. It holds the WAVs, `.jfxr` parameter files you can open in the [jfxr web app](https://jfxr.frozenfractal.com/), sequencing recipes and an `index.html` audition page. These sounds are not loaded by the game.

jfxr is BSD-3-Clause. Its author states that sounds made with it may be used without restriction.
